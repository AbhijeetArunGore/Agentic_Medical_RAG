# Agentic Medical RAG: Technical Design Document (2026 Edition)

## 1. Project Overview
**Objective:** Build a multi-agent Clinical Decision Support (CDS) system that ingest patient data, retrieves relevant medical evidence, and provides a verified, citation-backed briefing for clinicians.
**Core Stack:** Python, LangGraph (Stateful Orchestration), ChromaDB (Vector Store), Ollama (Local LLMs) / AWS Bedrock (Production LLMs).

---

## 2. Agentic Workflow (The LangGraph State)
The system operates as a directed graph with cycles for verification and self-correction.

### Nodes (Specialized Agents):
1.  **`historian`**: Parses patient documents (FHIR/PDFs) and identifies clinical trends.
2.  **`researcher`**: Performs Adaptive RAG. Queries internal vector stores and external medical APIs (PubMed).
3.  **`skeptic`**: The "Clinical Validator." Cross-checks research against gold-standard guidelines to detect contradictions.
4.  **`scribe`**: Consolidates the validated findings into a professional briefing with citations.

### Edges (The Flow):
- `START` -> `historian` -> `researcher`
- `researcher` -> `skeptic`
- `skeptic` -- (If contradiction found) --> `researcher`
- `skeptic` -- (If verified) --> `scribe` -> `END`

---

## 3. Data Ingestion & Engineering
- **Formats:** PDF (Labs), JSON (FHIR EHR data), CSV (Vitals history).
- **Processing:** 
  - Text Extraction (PyPDF2 / Unstructured).
  - Chunking: Semantic Chunking (preserving clinical context).
  - Embedding: `med-embedding-v1` (or local equivalent).

---

## 4. Verification & Trust Mechanism
- **Faithfulness Score:** Every claim generated by the Scribe must have a cosine similarity check against the source document.
- **Human-in-the-Loop (HITL):** Use LangGraph's `interrupt_before` to require clinician approval before final report generation.

## 6. Success Metrics (Elite Standards)
1.  **Hallucination Rate:** < 1% (via Skeptic Agent loop).
2.  **Citation Accuracy:** 100% of claims must link to source text.
3.  **Processing Latency:** < 15 seconds for a 50-page summary.
